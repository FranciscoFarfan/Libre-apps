# Tienda de Programas Libres

**Terminado** | **Uso de IA** | **Trabajo**

## Descripción
Esta aplicación de escritorio fue diseñada como una herramienta de valor agregado para los clientes de mi negocio de servicio técnico. Al finalizar una reparación o mantenimiento, se les deja este programa en sus equipos para que puedan explorar y descubrir alternativas libres y gratuitas a costosos programas de pago. La aplicación les permite ver opciones de software, leer sus descripciones, y les facilita enlaces directos y seguros para descargar las herramientas oficiales que necesitan. Es una forma de agregar profesionalismo y valor al servicio ofrecido.

## Características

### Funcionalidades
- **Catálogo de Software**: Lista interactiva de programas libres agrupados por categorías, mostrando explícitamente qué herramienta comercial pueden reemplazar.
- **Detalles Visuales**: Vista detallada con un carrusel interactivo de capturas de pantalla, información técnica (tamaño, versión) y características principales.
- **Navegación Intuitiva**: Interfaz de usuario amigable con barra lateral para filtrado de categorías y tarjetas de presentación estilizadas.
- **Descargas Directas**: Integración nativa para abrir enlaces de descarga o repositorios oficiales directamente en el navegador del usuario.

### Tecnologías Usadas
- **Python**: Lenguaje principal de desarrollo del proyecto.
- **Flet**: Framework de interfaz gráfica de usuario (GUI) moderno (basado en Flutter) para crear una experiencia visual atractiva, reactiva y fluida.
- **JSON**: Base de datos ligera utilizada para almacenar y administrar la información del catálogo de programas, permitiendo actualizar la lista sin tocar el código fuente.
- **PyInstaller**: Utilizado para empaquetar la aplicación en un archivo ejecutable `.exe` portable.

### Innovaciones
- **Orientado a la Experiencia del Cliente**: Implementación de un diseño moderno estilo "tienda de apps" (Dark Mode, gradientes, animaciones hover) que proyecta una imagen profesional, transformando una simple lista de recomendaciones en un producto premium.
- **Generación Dinámica de UI**: Renderizado de la interfaz completamente dinámico basado en la lectura del archivo JSON local, haciéndolo altamente escalable.
- **Gestión Automática de Multimedia**: Sistema inteligente que escanea el directorio local para agrupar y cargar en un carrusel dinámico tantas capturas de pantalla como existan para cada ID de programa.
