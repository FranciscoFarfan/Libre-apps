# Programas libres
#### Tienda de programas libres para windows
> Este programa fue desarrollado utilizando herramientas de IA

## Caracteristicas
- Permite visualizar programas
- Links a las paginas oficiales de los programas
- Link de descarga del programa
- Descripcion del programa
- Capturas de pantalla del programa
